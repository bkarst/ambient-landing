# Logo

The mark, wordmark, lockup and app icon, from the supplied halftone file.

Provide `variant` (`mark` · `wordmark` · `lockup` · `app-icon`), `size` (the cap height of the word for `wordmark` and `lockup`, the side for `mark` and `app-icon`) and optionally `tagline` (adds "Real-world insights. Quieter." under the word) and `ink` (`gold` by default, the colour the file was drawn in; `accent` for Ambient Yellow; `ink` to inherit the text colour).

- Use `lockup` in navigation and footers, `wordmark` where the mark would be smaller than 24px, `mark` alone only at 48px and above — the halftone dissolves into a blob below that.
- `app-icon` draws the mark on a Deep Navy tile with continuous corners; it is always navy, in both themes.
- Clear space is the height of the word on every side. Never recolour the dots individually, stretch the mark, or set the word in another face or weight.
- The wordmark is live type (Inter 600, tracked −0.03em), not an outline; no vector wordmark was supplied.
