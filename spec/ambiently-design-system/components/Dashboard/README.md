# Dashboard

The overview page, assembled: a `Sidebar`, a title row with a time-range `Select` and the one primary `Button`, four `Stat` tiles (one `hero`), then charts in `Card`s — a two-series `LineChart`, a grouped `BarChart`, a ranked horizontal `BarChart`, a single-series `LineChart` and two `Ring`s.

This is a showcase page, not a component: copy its layout (16px gutters, `space-8` page padding, 1.6:1 then 1.2:1:0.8 rows at 1280px) rather than importing it. Spend charts pass `upIsGood: false` to their deltas.
