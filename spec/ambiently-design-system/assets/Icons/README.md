# Icons

Line icons on a 24px grid, 1.5px stroke, round caps and joins, drawn in Deep Navy #0b1b3d so they show on light grounds; `<img>` cannot recolour them, so on navy use the `Icon` component (which inherits the text colour) or recolour in the design tool.

The eight brand icons from the sheet: `data`, `telemetry`, `connect`, `cloud`, `location`, `storage`, `security`, `people`. The rest are the UI set: navigation (`overview`, `sensors`, `alerts`, `settings`, `spend`, `model`), actions (`search`, `play`, `download`, `filter`, `plus`, `minus`, `close`, `check`, `more`, `external`), direction (`chevron-*`, `arrow-*`), and `info`, `calendar`, `clock`.

Redrawn to match the brand sheet's rendering; replace with the originals if source files exist.
