# Logos

- `ambiently-mark.png` — The mark as supplied: a 1254px halftone sun of 325 dots in gold #f9bb01 on transparency. The source of truth; use it at 48px and larger.
- `ambiently-mark.svg` — The same mark traced dot for dot from the PNG (centroid and area of every dot), single ink #f9bb01, on a 1000-unit square with 3% padding. Use it for print and for any size the PNG can't cover. It shows via `<img>` and keeps its gold; to recolour, use the `Logo` component.

The wordmark is live type (Inter 600, −0.03em) and has no file; the `Logo` component sets it. No vector wordmark was supplied.
